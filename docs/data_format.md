# 数据格式和真实边界
dataset.py按PWV月/日目录排序，用同名Radar文件存在性配对，拼接成全局列表，再按sample_step取30个连续列表位置；完全不解析PNG时间戳、不校验分钟间隔、UTC或跨日连续性。6分钟和0~120min是test.py时间坐标及研究任务假设，不是dataset所保证的事实。
PNG→Grayscale(1)→整幅Resize(64,64，torchvision默认双线性)→ToTensor→1-x。原图尺寸未检查；70×66是提供方背景信息，不能由此代码验证所有图像或地理边界。没有裁切、padding、随机增强。
输入10帧[B,10,2,64,64]、目标20帧，通道[PWV,Radar]；0..1浮点。测试将Radar乘50得到dBZ，Z=10^(dBZ/10)，R=(Z/200)^(1/1.6)，normalized<=.01另置雨强0。PWV毫米上限80来自用户资料，不是本源码显式反归一化常数。
原读取要求解压目录：PWV_2025_S/月/日/*.png和RADAR_2025_S/月/日/同名.png；无ZIP、ERA5、DEM V2加载器。训练stride10，test stride5。各脚本在各自全样本列表上按70/15/15索引划分，不是后期2062/283/450固定清单。邻近窗口共享帧，跨partition无purge，可能泄漏；禁止把这里当已证明时间独立的协议。
当匹配图像少于30时原len公式仍可能返回一个虚假窗口，在getitem中越界；保留原实现并记录缺陷，未修补。扩散协作必须先独立登记双方共用的连续、无重叠划分，不能静默改变历史模型后声称复现。
