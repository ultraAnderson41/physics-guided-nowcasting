# version1.0审计
唯一代码版本：原五份Python，共享model/dataset、两份各自定义损失的训练脚本和历史图形评价；没有第二套可运行模型、ERA5代码、扩散实现或配置/seed/依赖/权重。历史PNG文件名涉及不同实验，不足以确定其训练版本或对应权重，故不合并为新模型，也不声称指标。
完整目录清单见source_inventory.json，分类和函数行号见code_reference.md。地形ZIP、TIFF、OVR大资产与XML/TFW不复制；后两者含地理/处理记录但不能单独证明与模型DEM/雷达的配准，XML还含个人绝对路径，不适合直接公开。模型实际dem_64x64.pt在原版本同级父目录，本次不擅自纳入数据授权未知的发布包。
确认存在的问题：不连续帧直接拼接；短数据len虚假样本；stride10训练与stride5测试不同划分；相邻窗口共享帧可能泄漏；CUDA FP16硬编码；MSE时间分母和SSIM batch归一化；硬clip+替代sigmoid梯度衰减；cap参数反向None；P1/P2损失目标不一致；GAN last别名称best；测试缺权重随机回退。这些不是整理时修复的算法问题，全部保留并披露。
整理变更仅新增：路径配置、私有模块Dataset根路径替换、独立新输出目录、显式资产存在检查、轻量预测命名/输入检查、文档/合成测试。原模型、训练循环、损失、指标、网络结构和state_dict键不改。没有用后期稳定ERA5代码覆盖本版本，没有新建从未验证的统一模型。
参考仓库访问受限（抓取失败/公开API限流403），未能核实其实际文件结构，因此采用适合五份legacy文件的保守结构，不假借其实现或许可。实际源根只在本地审计记录中，不在共享文档硬编码个人路径。
