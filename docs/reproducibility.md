# 可复现范围与必要补充
本次可复现：模型构造、CPU随机权重合成20步、物理方向/门控、基本梯度、原源码与发布副本同权重一致性。不能宣称历史训练结果/论文指标复现。
历史工程没有requirements/lock/seed/manifest/配置文件/训练日志/权重；本机Python3.10与CPU依赖版本仅记录当前测试，不代表原RTX训练环境。torch与torchvision需匹配安装，CUDA版本按实际GPU确定，不由无依据的版本号伪锁定。无scikit-image/xarray/CDS/rasterio核心依赖。
完整历史复现仍需：同一原始数据与排序、匹配的DEM张量、可信state_dict、原训练环境/seed/版本说明、完整训练日志和模型选择依据；另外必须承认旧数据划分/损失/门控缺陷。修复这些将形成新实验版本，不能悄悄纳入本整理。
原目录未改，五份核心文件逐字节复制；大资产不读入/不打包，只比较尺寸与mtime，未声称其全量SHA核验。缺checkpoint时正式推理BLOCKED。DEMs数值单位/地理配准和共享授权仍待确认；可以组内协作评审，但公开开源许可未定。

构造API以临时工作目录适配旧DEM相对路径，只在单线程初始化阶段调用；forward不切换目录。保存/共享state_dict，不pickle整个动态加载模块。
